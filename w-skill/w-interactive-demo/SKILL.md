# 离线交互演示工具

把用户指定的交互演示做成真正能操作的本地文件。支持两种模式，优先根据链接、截图和对话上下文判断，不要求用户填写需求表。

## 选择模式

- **提取已有工具**：用户给出网页链接，指定页面内的演示、iframe 或截图。读取 [提取流程](references/extract.md)。保留原工具的行为、数据和交互；若无法提取，应说明原因，再判断是否需要询问用户改为重建，不能把新写的仿制品称为原版下载。
- **生成新工具**：用户给出教学主题，要求“按这个思路／风格做一个”。读取 [生成流程](references/create.md)，把主题转为少量有解释力的可调参数、图表和反馈指标。
- 两种模式都读取 [风格与交付](references/style-and-delivery.md)。后续修改优先直接编辑用户正在使用的文件，并同步已有压缩包。

## 本用户的默认约定

以下是用户在建立此 skill 时认可的默认做法；以后明确提出的新要求优先。

- 使用类似 Google 机器学习速成课程交互工具的浅色界面：克制的标题、浅灰容器、白色图表卡片、紫色／橙色类别、蓝色曲线。
- 新工具优先中文说明，参数或指标可使用英文＋中文；提取工具默认保留原界面语言。
- 页面底部默认显示 `工具来源：AIHelper01`。提取第三方工具时，真实来源链接、提取日期、改动说明及必要许可署名另存于随包 README，并保留代码中的版权声明；展示署名不替代法定署名要求。
- 优先单文件 `index.html`，双击后在现代浏览器中离线使用。不为一个教学演示引入不必要的框架、安装步骤或后端。
- 默认把每个演示保存到当前工作区的 `examples/<tool-slug>/`，并把 ZIP 放在 `examples/` 下。已有 `examples/` 时沿用其命名规则；没有时创建该目录。不要固定依赖创建本 skill 时的磁盘路径。
- 创建演示并不自动修改仓库根目录的主页 `index.html`。只有用户明确提出“同步到 index”“加到主页／首页”或同等意思时，才把工具卡片加入主页并同步分类数量、链接和说明；不能从用户要求制作工具推断出主页更新授权。

## 完成标准

1. 明确演示对象，检查已有文件，避免覆盖无关成果。
2. 完成提取或生成，补齐运行所需资源和简短中文使用说明。
3. 在浏览器中实际检查关键操作；宣称可离线前，使用无缓存的新上下文阻断 HTTP(S) 请求，确认无必需外部请求、无运行错误。直接打开 `file://` 验证双击使用。
4. 核对一组可独立计算的数值或业务不变量，并查看真实截图确认布局。不能只用页面能加载、属性被赋值或自定义事件被派发来证明操作正确。
5. 打包最终版本，排除测试依赖和临时文件；最终答复给出 HTML 和 ZIP 的绝对路径链接，简述已验证的行为与实际限制。

若工具依赖不可取得的服务端接口、登录状态或浏览器能力，准确区分已完成与仍依赖联网的部分，不承诺“完全离线”。
