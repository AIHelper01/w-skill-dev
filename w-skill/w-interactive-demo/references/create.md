# 生成新的教学演示

## 先确定教学关系

将用户主题归纳为“用户调节什么 → 什么图形变化 → 哪个数值帮助解释”。只添加能解释该主题的功能；训练、数据集切换、动画等按需加入，不把逻辑回归案例的功能清单强加给每个演示。

沿用对话中已有工具的风格与术语。无需用户再次指定已经明确的署名、离线要求或语言。新创作的工具要准确说明是新制作，而不是从参考站点下载。

## 实现原则

- 小型演示优先原生 HTML、CSS、JavaScript 与 SVG；数据和样式嵌入文件。较复杂的模拟可选 Canvas 或确有必要的库，但将其随包交付。
- 分离模型状态、计算函数与渲染。使用一个状态来源驱动控件、图形和指标，避免旧值残留。
- 用完整精度保存训练或模拟参数，显示时再取舍小数。不要把带 `step="0.1"` 的 range 元素当成梯度下降参数的唯一存储，否则每次赋值会量化参数，使训练停滞或失真。
- 示例数据固定或使用固定随机种子，保证教学可重复。若生成新数据，提供明确操作，并标明是合成示例。
- 允许的参数范围应覆盖有教学意义的状态；约束参数或停止训练时给出适当提示。动画要能暂停，重置和切换场景时处理计时器。
- 轴标题、单位、图例和颜色含义明确。为防遮挡而抖动样本位置时，注明其仅用于显示，避免把抖动量当成真实数据。
- 对未定义的指标、除零、空数据和极端输入使用有说明的表示，不用随意填零掩盖问题。

## 本系列风格的例子

逻辑回归可以包含：三个固定示例数据集，权重／偏置／分类阈值，Sigmoid 概率曲线、分类边界、混淆矩阵、交叉熵，以及可选的单步或自动训练。中文解释每个控件，必要时保留英文术语以对应教材。

这只是已认可的设计例子；新的主题应选用适合自己的图形和指标，例如聚类展示中心与距离，梯度下降展示损失曲线和迭代位置。

## 数值与教学验证

用独立计算或简单已知样例校验结果，而不是只复用页面函数作为期望值。选择与主题相关的少量不变量即可。

逻辑回归例子：

- `p = sigmoid(w*x+b)`，`w=0,b=0` 时所有样本概率为 0.5；明确采用 `p >= threshold` 为正类。
- `TP+FP+FN+TN` 等于样本数；准确率、精确率、召回率与混淆矩阵对应。
- 使用 `2*TP/(2*TP+FP+FN)` 计算 F1：分母大于零但 TP 为零时，F1 为零；不能仅因 precision+recall 为零就一律显示未定义。
- 只调分类阈值不改变概率曲线和交叉熵；改权重或偏置才会改变概率。
- 训练使用合适步长；在已知样例上验证损失改善、暂停和重置。不要宣称任何步长或任何迭代必然下降。
- `w=0` 且全部概率恰好等于阈值时不存在唯一分类边界，需说明所有样本按等号规则分类，而不是简单写“边界在图外”。

这些细节约束相应数学主题，不要求所有演示实现这些指标。
