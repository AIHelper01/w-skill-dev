# 默认风格与交付

## 视觉约定

用户认可的是类似 Google 机器学习教学演示的克制布局。优先保持一致性，不添加营销式首屏或与教学无关的装饰。

| 用途 | 默认值 |
| --- | --- |
| 页面 | 白色 `#ffffff` |
| 演示容器 | 浅灰 `#f8f9fa`，边框 `#dadce0` |
| 正文／次要文字 | `#202124`／`#5f6368` |
| 正类／负类 | 紫色 `#9334e6`／橙色 `#f9ab00` |
| 预测曲线 | 蓝色 `#1967d2` |
| 字体 | Arial、Microsoft YaHei、系统 sans-serif；数值用 Consolas 或系统 monospace |

- 内容宽度约 1000–1120px；页面标题 24–26px，小节标题 18px，正文 14–16px。
- 浅色容器内先放控件，再放主图，下方放指标或矩阵。白色卡片、约 8px 圆角、细边框、轻阴影。
- 控件明确显示名称与当前值，滑块标出范围；按钮文案描述实际操作。
- 提取已有工具时保留内部布局，外层只补充必要标题、中文使用提示和页脚。
- 窄屏变为单列，避免页面横向溢出。图表字体和点不能因整体缩放变得不可读；可以重新布局，或给单个图表独立横向滚动并提示用户。
- 保留键盘操作、可见焦点、输入 label；颜色之外用文字或符号说明类别。不要在动画每帧播报大量无障碍文本。

## 默认输出

```text
examples/
  <tool-slug>/
    index.html
    README.md
    assets/       # 仅实际需要时
    licenses/     # 仅相关资源要求时
  <tool-slug>.zip
```

默认使用当前工作区根目录下的 `examples/`；已有该目录时沿用其中的目录命名风格，没有时创建。单文件足够时只交付 HTML 与 README。README 简述打开方法、控件作用及来源／限制；新建工具注明为新制作，提取工具记载真实原站出处。README 中英双语、默认英文，同目录两个文件：`README.md` 存英文（一级标题下紧跟 `**English** | [简体中文](README.zh-CN.md)`），`README.zh-CN.md` 存简体中文（紧跟 `[English](README.md) | **简体中文**`），正文不混排两种语言，`scripts/check_repo.py` 会检查这一结构。不要带入依赖安装目录、原站整页快照、调试脚本或测试截图，除非用户要求。

演示目录内的 `index.html` 是工具入口，仓库根目录的 `index.html` 是主页，两者不可混淆。默认不编辑根主页，也不自动添加工具卡片。只有用户明确说“同步到 index”“加到主页／首页”“更新工具导航”或表达同等意图时，才更新根主页；更新时把工具放入合适分类，并核对分类计数、本地链接或外链属性。

Windows 本地文件使用绝对路径链接。用户修改工具后，同步刷新已有 ZIP，确认归档中是修改后的版本。

## 浏览器核验

1. 在新的浏览器上下文中打开 `file://` 成品，避免服务工作线程或缓存掩盖依赖；阻断 HTTP(S) 资源请求，记录必要外部依赖和运行错误。
2. 操作关键可见控件，检查图形、数值和状态一起变化；训练按钮验证启动／暂停／重置，选择器验证数据确实切换。
3. 核对少量核心数学不变量或原站已知值；仅检查 DOM 元素存在不够。
4. 查看桌面与窄屏截图，修复遮挡、误导性图例和溢出。按改动风险选择检查，文字替换不必重跑完整数学测试。

优先使用已有浏览器工具或已安装的自动化依赖。确需安装测试依赖时放在专用临时目录，成品仍应无需用户安装软件。删除临时目录前校验其绝对路径确实位于指定工作区，避免影响其他成果。

## 最终答复

给出“直接打开 HTML”和“下载 ZIP”两个链接，用一两句话说明主要操作与实际验证结果。单纯改字时只说明已修改和同步打包。未测试某种交互、移动端或完全离线时，不将其写成已经验证。
