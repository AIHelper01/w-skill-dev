# w-slide-lecturer

A portable Agent Skill for writing slide-faithful English lecture scripts with Chinese visual cues.

## Install
Copy the `w-slide-lecturer` directory into the agent's supported skills directory (for example, `.agents/skills/` or `~/.agents/skills/` in compatible Codex setups). Keep `SKILL.md` at the root of the skill folder. Follow your agent's skill-loading instructions.

## Typical prompts
- `Use w-slide-lecturer to write the English teaching script for the attached Slide 24. Keep original text and visual order.`
- `Use w-slide-lecturer to revise slides 17–20 without trimming PPT content.`
- `Use w-slide-lecturer and output A1/A2/B/C for each slide.`

## Contents
- `SKILL.md`: behavior and quality checks
- `references/style-guide.md`: wording and fidelity conventions
- `references/output-formats.md`: standard and extended outputs
- `examples/sample-slide.md`: concise chapter transition example
