### 页面衔接：Agent Action → Agent Memory

We have learned how Agents use tools through **Function Calling, MCP, and Skills**.

But here is another important question: **How does an Agent remember useful information while working on a task?**

For our Shanghai trip, it may need the budget, travel dates, and weather results. Without memory, it may repeat work or forget an important requirement.

### 第四章 Agent Memory

Our next chapter is **Agent Memory: From Short-Term to Long-Term**.

Short-Term Memory helps with the current task. Long-Term Memory keeps useful information for future tasks.

### 页面总结与过渡

Planning decides what to do. Action helps the Agent use tools. **Memory helps the Agent remember what matters.**

Let's start with Short-Term Memory.
